Admin kompyuter:

O‘quvchi kompyuteridan ochiladigan manzilni kiriting. IPv4’ni ipconfig orqali topasiz.

ZIP’ni o‘quvchi kompyuterida oching va AGENT-INSTALL.bat’ni administrator sifatida ishga tushiring. Keyin Windows hisobidan chiqib qayta kiring. IP yoki kalitni o‘quvchi kompyuterida yozish kerak emas.

Paket 8 soat amal qiladi. Uni faqat maktab kompyuterlariga bering. Qayta o‘rnatish mavjud ulanishni saqlaydi.

Ulanish va yangilash

Agent ma’lumotlari HTTPS orqali shifrlanadi va paketdagi server sertifikati bilan tekshiriladi. Har bir kompyuterga alohida kalit beriladi.

Admin kompyuterda TCP 8766 portiga xususiy tarmoqdan ruxsat kerak. Buning uchun paketdagi ADMIN-FIREWALL.bat’ni admin kompyuterda administrator sifatida oching.

4.0 versiyaga o‘tishda eski agentlarni yangi paket orqali yangilang. Tizim agenti kompyuter yoqilganda, ekran yordamchisi Windows hisobiga kirilganda boshlanadi. O‘quvchida kuzatuv belgisi va mahalliy pauza tugmasi ko‘rinadi.
